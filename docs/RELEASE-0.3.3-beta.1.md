# ArchiveDesk 0.3.3 Beta 1（build 9）

面向 iPhone、iPad 和 iPhone Duo；最低 iOS / iPadOS 26.0。
未签名 arm64 真机 IPA，安装前需要使用自己的有效证书和描述文件重签。
保留 Xcode 27.1 beta / 27.1 SDK 的 Duo 专用布局，不是模拟器包。

## 新增与改进

- 音乐预览显示内嵌标签、专辑封面及音频参数。MP3 ID3、FLAC/Vorbis、
  M4A 使用源码构建的 FFmpeg；JPEG/PNG 封面也由开源后端解码。
  只读，不修改标签、不联网获取封面；不等同于 Mp3tag 编辑器。
- 修正 AV1 小窗的音视频调度：有界视频队列与画面提交分离，PCM 预缓冲、
  音频时钟同步及片尾队列排空，避免等待视频时间戳时饿死音频解码。
- 6／8／12／16 GB 内存策略：视频最长边 480／640／640／640，视频队列
  6／8／12／12 MiB。低电量、严重发热或低余量时，新预览采用保守档。
  不降低音频质量；输出降采样不等于降低 AV1 输入解码分辨率。
- 暂停／结束停止画面轮询，降低暂停工作线程和空闲性能面板采样频率；
  复用颜色空间，限制 UI 时间更新频率，失败时清理解码与暂存资源。
- 保留跨目录多选／整目录解压、多来源 ZIP/TAR 打包、CPU/RAM／速度／
  进度、闭箱／开箱图标及按系统文件授权与可写能力决定输出位置。
- 加密内容必须成功解密并通过完整性检查后才能显示媒体、标签和封面。
  RAR 密码读取受支持；**密码 ZIP／7z 仍不支持**，不会绕过拦截。

## 本轮验证（2026-10-19）

- iPhone Air / iOS 27.2：真实 AV1＋AAC、FLAC、UTF-16 文本和 JPEG；
  新 FLAC 的真实内嵌封面／标签；密码 RAR 预览门禁与错误密码重试。
  同一 AV1 完整播放后复测，用户确认 build 9 画面、声音正常、没有退出。
- 完整诊断播放：2,765 提交＋54 丢弃／替换＝2,819 解码视频帧；音频队列
  空后补充计数为 0。这是应用队列指标，不是系统音频 xrun 测量。
- 复测中的两次采样约 94–95 MB、单核 51–54% CPU；不是峰值或性能保证。
  初次退出报告与开发端主动重启诊断会话吻合；未发现对应时段新崩溃／
  jetsam 报告。此前写盘资源警告未导致系统终止，不宣称所有崩溃均已排除。
- 同一台 iPad M5 / iPadOS 27.2 模拟器：常规媒体与强制 6 GB 策略通过，
  验证 640×360／480×270 视频、未缩小的 900×900 JPEG、播放／暂停／跳转。
  音乐标签／封面、RAR 密码重试等 UI 回归也通过。
- 主机核心 118 项通过，无跳过；四档预算／有界缓冲、音乐标签／封面及
  加密媒体专项通过。最终未签名构建、对应静态重链接与附件哈希另行核验。

## 仍有限制

没有实测 6／8 GB 真机内存压力、jetsam 或能耗；模拟器档位不模拟其硬件。
本轮不复测 USB、ISO 或 23 GB 来源，历史验证及遗留项见
[iPad 真机记录](https://github.com/HachiMiku39/archivedesk_ios/blob/main/docs/PHYSICAL-QA-0.3.2.md)。
打包完成后保存目录显示旧值、USB 零速度等待段仍未修复。
媒体预览上限 512 MiB，图片 32 MiB，文本 256 KiB，封面另有有界限制。
不支持 PDF／Office、HEIC／AVIF／GIF 渲染、HDR 色调映射和图片方向元数据。
只创建 ZIP／TAR，不创建 RAR、7z 或任何加密压缩包；不提供分卷流程。
输入使用本机私有快照，会额外占用空间；后台会取消任务，无断点续传。
