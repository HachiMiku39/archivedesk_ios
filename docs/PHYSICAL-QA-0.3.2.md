# 0.3.2 build 5 真机验证 — 2026-10-07

测试设备：iPad Pro 11-inch (M4)，iPadOS 27.2。应用为自行重签安装的
0.3.2 build 5；测试对应应用源码提交 `47b446f`。发布未签名 IPA 的
SHA-256 为 `72f46f608185e8ddeff138b798296972fc3dd39e653634e39922c42757398684`。
本轮没有修改应用代码或修复下列已知问题，未增加 build 号。

## 本地 Documents

- 93,737,342 字节的四类媒体来源：AV1＋AAC 视频、FLAC 音频、UTF-16LE
  日志和 JPEG。ZIP 与 TAR 创建／重新打开／全部解压通过，四个结果
  文件的 SHA-256 均与原文件一致。未重现旧版 ZIP/TAR 初始化立即报
  “decoder safety budget” 错误；不是对原先 20 MB 文件夹的逐一复测。
- JPEG 可见；UTF-16 日文及英文文本正确显示；FLAC 播放时间推进并可
  暂停；AV1 视频显示画面并可暂停。声音可听性、完整播放、音画同步
  尚未确认，主机完整软件解码测试与此真机短时预览测试分开记录。
- 约 6.35 GB UDF ISO 浏览／解压通过：1,065 个文件，6,360,050,686 字节。
- ISO 解出的目录与媒体目录拼成 ZIP，再完整解压，1,069 个文件、
  104 个目录、6,453,788,028 字节的路径与文件 SHA-256 全部一致。
  包含大于 4 GiB 的文件：5,394,922,312 字节。参考 ISO 同样由源码
  7-Zip UDF 后端读取，因此不是两个独立 ISO 解码器的交叉验证。
- 两个媒体文件多选解压及整个媒体文件夹解压通过 UI／实际文件列表
  检查；这两项后续输出没有单独做 SHA-256。
- 本地大 ZIP 创建 92.2 秒、平均 70.0 MB/s；回读解压 20.0 秒、
  平均 322.9 MB/s。运行中 RAM 样本约 55–56 MB，不是峰值测量。

## 外置 USB

系统“文件”选择器实际显示外置卷；用户报告格式为 exFAT。通过系统
目录选择器授权，在独立新建测试目录内输出，不修改原 ISO 或媒体。
来源仍按应用设计导入本机私有快照；这不是完全不占本机空间的 USB
到 USB 零暂存模式。所有速度为应用显示值，不是 5 Gbps 链路带宽测量。

| 操作 | 处理内容 | 用时 | 平均速度 | 验证 |
| --- | --- | --- | --- | --- |
| 媒体文件夹解压到 USB | 93.7 MB | 0.6 秒 | 169.3 MB/s | 100%，实际四文件及大小 |
| USB 媒体来源创建 ZIP 到 USB | 93.7 MB | 1.6 秒 | 59.0 MB/s | 实际 ZIP，重新打开成功 |
| USB 原始 ISO 打开并解压到 USB | 6.36 GB 输出 | 75.3 秒 | 84.5 MB/s | 100%，实际 11 个顶层项目 |
| USB ISO 解出目录＋媒体目录创建 ZIP 到 USB | 6.45 GB 输入，6.32 GB ZIP | 108.3 秒 | 59.6 MB/s | 100%，实际 ZIP，两个来源目录可浏览 |
| 新 ZIP 完整解压回 USB | 6.45 GB 输出 | 155.2 秒 | 41.6 MB/s | 100%，实际两个目录，无解压／CRC 错误 |

打包运行样本：63.9%，67.2 MB/s，CPU 85.1%（100% 为一个核心），
RAM 55.8 MB。解压样本 RAM 约 56–57 MB，进度／速度／CPU／RAM 实时显示。
本次未出现目录来源验证拒绝、空间不足或内存安全预算错误。

USB 回读经过应用 CRC 校验，但没有独立读取最终 USB 文件逐个做
SHA-256；不能将本地往返的全哈希结果移用到 USB。短任务速度受缓存
影响，不能用来承诺持续读写速度或设备峰值性能。
