# ArchiveDesk 0.3.3 Beta 2（build 10）

未签名 arm64 真机 IPA，最低 iOS / iPadOS 26.0。使用 Xcode 27.2 beta（27B5028f）和 iOS 27.2 SDK（24B5089g）构建，安装前须用自己的有效证书及描述文件重签；不是 App Store／TestFlight 分发。

## 更新

- 修复未标记 UTF-8 的旧式中文 ZIP 文件名乱码；优先遵守 UTF-8 标记和 CRC 有效的 Unicode 文件名扩展，区域编码自动识别不确定时回退 CP437。
- 新增独立的 ZIP 文件名编码菜单；重新索引而不修改原包，失败时保留原索引和快照。
- 文本预览新增独立正文编码菜单，支持 GBK／GB18030、CP932、Big5、CP949、CP437／850、Windows-1252／1251、CP866，以及 UTF-8／UTF-16LE／BE。自动识别存在歧义时可手动恢复，无需再次解压。
- ZIP Deflate 直接按已验证的局部头／数据偏移流式读取，避免另一套文件名解码导致“显示正确却找不到内容”。继续校验原始名称、边界、长度、流结尾、CRC，并保留安全路径、取消和回滚。
- 编码转换在后台执行，原始正文重试缓存最多 256 KiB；切换文件、取消、进入后台及内存警告时清除。不持久保存密码或明文预览历史。
- 保留多来源 ZIP／TAR 创建、多选和整目录解压、密码 RAR、开源媒体／音乐标签及封面、CPU／RAM、速度／进度和自适应布局。没有扩大加密格式支持范围。

旧编码转换使用原本已链接的开源系统 iconv，Deflate 使用系统 zlib；没有新增闭源媒体解码器或网络探测服务。

## 验证

- 主机编码专项 67 项通过；核心 115 项通过、两项桌面文件协调明确跳过；格式 36 组、打包／密码 RAR 20 组通过。
- 同一台 iPhone 18 Pro／iOS 27.2 模拟器：3 项原生 UI 测试通过，0 失败、0 跳过。验证用户原 ZIP 的中文目录、GBK TXT 预览和单项解压，手动文件名／正文编码恢复，以及 CP437／Deflate 回归。
- 原 ZIP 的全部 9 个输出在主机测试中逐一通过大小和 CRC 校验；原始文件不修改。私人 ZIP、正文、媒体和截图不随源码或 IPA 发布。
- 本轮未复测真机、Duo 折叠、USB／ISO、AV1 性能或低内存压力；历史真机证据不代表 build 10 已在真机重新验证。详情见 [编码专项记录](ENCODING-QA-BUILD10.md)。

## 下载与限制

附件包括 `ArchiveDesk-0.3.3-unsigned.ipa`、完整对应源码、匹配的 arm64 应用对象／静态库重链接材料，以及 SHA-256 清单。保留 LGPL、unRAR 附加限制、FFmpeg、dav1d 等许可；旧 Release 保留。

自动编码识别不是通用保证，短文本、混合编码或错误标记可能需要手动选择。密码 ZIP／7z 及加密创建仍不支持；密码 RAR 必须成功解密和校验后才能预览。文本上限 256 KiB、媒体 512 MiB、图片 32 MiB。任务进入后台取消；23 GB／网盘／只读及拔盘、实际低内存／能耗仍待验证。任务页保存目录旧值和 USB 等待段问题未修复。
