# ArchiveDesk 0.3.2 Beta 1（build 5）

面向 iPhone、iPad 与 iPhone Duo 的测试版。最低 iOS / iPadOS 26.0，
IPA 为 **未签名 arm64 真机包**，不是模拟器包；安装前需要自行重签。
本次 IPA 与已完成 iPad 真机测试的本地 0.3.2 build 5 相同，无需仅为
GitHub 发布重新安装。2026-10-07 更新实测说明，不增加 build 号。

## 本版改进

- 显式“解压全部内容”和“解压整个文件夹”；跨目录多选文件／文件夹，
  递归包含子目录，父子重叠选择去重，不覆盖原有输出内容。
- FFmpeg 9.0.2＋dav1d 1.5.4 源码后端进行有界图片、音频、视频预览，
  提供播放／暂停／跳转；系统只显示已解码像素并播放 PCM。
- Swift UTF-8 与带 BOM 的 UTF-16 文本预览；真实日志已验证。
- 加密条目在成功解密和完整性检查之前不能预览，能看到文件名不代表
  可以预览内容。密码 RAR 支持；**密码 ZIP／7z 仍不支持**，不会绕过拦截。
- 解压及 ZIP/TAR 打包输出统一按系统“文件”授权和实际可写能力判断，
  包括本地下载、USB、iCloud、支持写入的第三方提供商；取消之前的
  第三方网盘只读限制，不再因无法识别来源拒绝写入。只读、授权失效、
  拔盘和提供商实际 I/O 错误仍会报告，保存完成不等于云端上传完成。
- 修订 UTF-8 初始化兼容性，初始化失败不再误报内存额度不足；错误包含
  阶段、errno 和编解码器在用内存。不放宽真正的内存安全限制。
- 保留 UDF／混合 ISO 读取、CPU/RAM、速度／进度、多来源 ZIP/TAR 创建、
  密码 RAR4/RAR5 只读后端、中性 App 图标和闭箱／开箱操作图标。
- 音频会话配置在后台进行，iOS 27 异步激活，iOS 26 使用非主线程兼容路径。

## 限制

仅创建 ZIP（Deflate）和未压缩 TAR，不创建 RAR、7z 或加密压缩包。
多卷、RAR 修复、PDF／Office 文档渲染、HEIC／AVIF／GIF 预览未实现。
预览媒体最大 512 MiB、图片 32 MiB、文本 256 KiB；输出像素最长边
1280。配置的解码器不保证所有编码变体，HDR 色调映射及图片方向元数据
尚未处理。打包来源先复制为本机私有快照，会额外占用空间；当前为前台
任务，进入后台会取消，不提供跨启动恢复。
