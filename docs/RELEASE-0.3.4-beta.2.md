# ArchiveDesk 0.3.4 Beta 2（build 12）

适用于 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.0。安装未签名 arm64 真机 IPA 前，请使用自己的 Apple 签名证书及描述文件重签。[发布附件](https://github.com/HachiMiku39/archivedesk_ios/releases/tag/v0.3.4-beta.2)

## 修复

- **解压覆盖**。用户打开覆盖提示后，如果另一个应用保存了目标文件，直接解压和暂存后合并都会停止，并保留新保存的版本。创建普通输出文件时持有同一个文件句柄直至写入结束。
- **连续冲突和密码重试**。覆盖按钮只答复原任务的那一次询问。密码校验在上一张弹窗关闭后开始。取消 RAR 密码重试会清理该操作持有的私有副本，迟到的校验结果不会再次索要密码。
- **音视频预览**。快速拖动进度条时，丢弃早先定位请求产生的缩略图或解码错误。播放失败后，等待缓冲或暂停中的解码任务可以退出并释放预览资源。

## 验证

| 环境 | 已通过的检查 |
| --- | --- |
| Mac 主机 | 核心套件 188 项。格式回归覆盖 ZIP、7z、TAR、单文件压缩流、RAR 和 ISO/UDF。打包回归包含 20 MiB 本地目录分别生成 ZIP/TAR 并逐块比对解压结果。 |
| iPhone 18 Pro 模拟器，iOS 27.2 | 连续处理同名文件、RAR 错误密码重试后预览与解压、取消密码返回浏览器。已核对随机目录和输出暂存默认关闭。 |
| 媒体解码主机测试 | 合成视频连续定位 76 次后，按最终画面的像素验证最后一次定位生效，并验证播放结束和重播。 |

本轮没有在实体 iPhone、iPad 或 exFAT 盘上复测。目录写入仍受系统选择器授权和文件提供商能力约束。外部程序并发移动父目录时，部分操作仍按路径寻址。直接解压中途失败可留下部分输出。输入归档和打包来源的内部快照仍需要内置空间。[存储规则](STORAGE-ACCESS.md) · [历史真机测试](PHYSICAL-QA-0.3.2.md)

## 下载与校验

下载同一标签下的未签名 IPA、对应源码、静态库重链接材料及 SHA-256 清单。在这四个附件所在的文件夹运行以下命令。

```sh
shasum -a 256 -c ArchiveDesk-0.3.4-SHA256SUMS.txt
```
