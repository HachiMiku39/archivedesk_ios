# ArchiveDesk 0.3.4 Beta 1（build 11）

未签名 arm64 真机 IPA，最低 iOS / iPadOS 26.0。安装前需要自行重签。

## 解压行为

- 默认直接解压到所选目录，不随机创建目录，不建立完整输出暂存，也不额外执行整包测试。解码器自身的 CRC／认证和错误检查仍保留；打包验证流程继续保留。
- 遇到已有普通文件，提供“覆盖此文件”“全部覆盖”“不覆盖”和取消。全部覆盖仅对当前任务有效；同名目录合并，链接及文件／目录类型冲突继续拒绝。
- 覆盖前在同目录将原文件改名为 `ArchiveDesk-backup-UUID`；不复制大文件，不自动删除备份。等待决定时改变了的目标会拒绝覆盖。
- 随机命名子文件夹和解压暂存只在 信息 → 设置 中开启，默认关闭。暂存位于目标磁盘。两个开关独立，可选择直接解压到随机目录，或暂存完成后合并到所选目录。
- 直接模式失败或取消可能留下不完整文件；不会递归删除所选目录。选择取消冲突时，尚未开始写解压内容。可选暂存仍只清理本任务自己的临时目录。

## 验证与限制

- 主机核心 174 项检查通过，覆盖直接／暂存、逐个覆盖／全部覆盖／跳过／取消、原文件备份、可选随机目录和符号链接拒绝；直接覆盖发生 CRC 错误时，目标目录、无关文件和原件备份保持完好。
- 36 组格式回归通过；新增 ZIP、7z、TAR、压缩流、RAR、ISO/UDF 的直接输出比较，及原生格式“全部覆盖”仅询问一次的检查。
- 同一台 iPhone 18 Pro / iOS 27.2 模拟器：1 项原生 UI 流程测试通过，0 失败、0 跳过，40.76 秒。验证首次直接输出、连续“不覆盖／覆盖此文件”、全部覆盖只询问一次、取消，以及随机目录／暂存只在设置出现且默认关闭。等待目标窗口和决定窗口完全关闭后才继续解码，避免连续询问丢失。首次使用无测试目标的构建 scheme 未运行测试，随后 UI 暴露重复辅助功能节点和关闭动画竞态，修正定位及交互生命周期后通过；不将初次失败计为通过。
- 未复测真实 USB、网盘、拔盘、低内存压力、Intel 或 AV1 性能。既有文件协调授权、密码门禁、旧编码、开源媒体／音乐信息及资源策略保留，不将历史真机结果计作本版新验证。
- **打开压缩包和添加打包来源仍会建立内部快照**。这与解压输出暂存不同，仍可能受到内置容量限制；本版不声称完成 USB 到 USB 的全程零副本。媒体预览和提供商也可能使用临时数据。
- 发布附件包括 IPA、对应源码、LGPL／unRAR／FFmpeg 等许可和匹配的对象／静态库重链接材料，以及 SHA-256 清单。旧版保留，私人样本和截图不发布。
